I'm a fourth-semester CS student at COMSATS Lahore and a web developer. I work across the stack, mostly with Java, JavaScript, TypeScript, and Python. I'm also interested in what happens beneath the application layer, particularly web servers, HTTP, and concurrency, which I've been exploring while contributing to Apache Tomcat.

### Things I've built

- **Cineby** — a Java/JavaFX media recommendation system with trie-based search, watchlists, reviews, and graph-based recommendations.
- **DocuVault** — a JavaFX document versioning project with authentication, version history, and LCS-based diffs.
- **AuraCheck** — an AI hackathon project for interview practice, with live voice sessions and feedback. Built with a team using React, TypeScript, FastAPI, WebSockets, and CrewAI; I worked on the frontend.

### What I'm exploring
